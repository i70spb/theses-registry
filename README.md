## Что это
Третий слой библиотеки: человеческий смысл без терминов. Термины живут в графе (bo840-graph),
шаблоны и реакции — в кейсах (bo840-cases), здесь — то, что понятно без библиотеки.
Библиотека вечна — сменяются редакции и носители.

## Структура
- `ПРАВИЛА_СОЗДАНИЯ_ТЕЗИСОВ.json` — КОНСТИТУЦИЯ. Читать первым. Восемь+один разделов: единица, постоянство, жанр, теги, счётчик, вход, идиомы, архитектура, искажения.
- `тезисы_МАСТЕР_v10.json` — ПРОИЗВОДНЫЙ сборник. Не истина; пересобирается слиянием пластов. Источник истины счётчиков — журнал внутри.
- `пласты/` — ИСТИНА. Неизменяемые входные файлы. Новое — новым пластом. Правка — только новым пластом.

## Бут (для алгоритма)
1. Прочитать ПРАВИЛА целиком.
2. Прочитать шапку мастера (правила идентичны файлу правил).
3. Работать с мастером; при расхождении мастера и пластов — пересобрать слиянием.
4. Итог сессии — новый пласт (неизменяемый) + журнал.

## Для человека
Открой мастер и читай тезисы как глоссарий жизни: каждый самодостаточен, теги — якоря для поиска.
Счётчики (+N-M) показывают, сколько раз правки соглашались/не соглашались с тезисом.

## Связи
- Граф терминов: репозиторий `bo840-graph`.
- Граф кейсов: репозиторий `bo840-cases`.
- Переход между слоями: поле `понятие_источник` у тезиса, связи кейсов к узлам графа.

## Якорь
Верификация соответствия источникам — по протоколу ⚓=XY (краткость×скепсис),
спецификация в линии БО840 (ПРОТОКОЛ-00, 2026-03-15). Стопроцентное соответствие — ⚓=10
(замороженное состояние, вне шкалы).
